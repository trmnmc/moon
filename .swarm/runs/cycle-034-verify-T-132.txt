MECHANISM. node:util wraps the offending token in ITS OWN quotes. When the token itself
begins with an apostrophe, the raw message contains ''x'' — and `*` (unlike `+`) happily
matches that leading EMPTY pair and stops. So the shipped fix makes `moon "'x'"` report an
empty token where it previously reported `x`. Strictly worse: it does not merely fail to
improve, it replaces correct information with wrong information.

This violates acceptance clause 2 ("STRICTLY NO OTHER BEHAVIOR CHANGE"). The change is
reverted rather than shipped-because-net-positive: `moon ""` is likelier than `moon "'x'"`,
but "the common case got better than the rare case got worse" is exactly the trade the gate
rules forbid weighing, and a correct fix (below) exists.

TWO THINGS THIS SETTLES.

(a) The greedy anchor /'(.*)'/ is the ONLY candidate correct on every row, including all
    the option-code rows. It is safe here for a reason visible in the raw dump: node:util
    emits exactly ONE quoted token and NO other apostrophes in any of its three
    ERR_PARSE_ARGS_* messages — there is no "Did you mean '--json'?" suffix to be swallowed.
    (Measured on Node v24 locally; CI covers Node 20 and 22. A retry test must PIN this,
    because greedy's safety is a property of node:util's wording, which is not a stability
    guarantee. Also note `.` does not match a newline in JS, so a token containing \n is
    still unrecovered — a residual to state, not to bury.)

(b) A WIDER, PRE-EXISTING defect on main, not previously known and not what T-132 was filed
    for: `moon "it's"` reports `unexpected argument 'it'` — the token is TRUNCATED at the
    user's apostrophe. Same line of code, same root cause, and MORE reachable than the
    empty case. T-132's acceptance is widened to the class rather than a second item being
    filed. The widening is forced by the evidence, not chosen: any rule that names the
    empty token must also handle a leading apostrophe, since both come from the same
    spurious-quote-pair mechanism. A narrow instance fix is provably regressive here — the
    shipped attempt IS that narrow fix, and G2 is what it cost.
